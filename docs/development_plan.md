## 6. 技术债务与优化项

以下项目不影响功能使用，可在后续版本中逐步处理：

| 项目 | 说明 | 优先级 |
|------|------|--------|
| PDF 解析规则覆盖 | 当前仅 2 个内置 PDF 规则，更多发票类型需补充 | 中 |
| 单元测试 | 凑票模块已有 54 个测试用例，其他模块仍需补充 | 高 |
| 打包分发 | PyInstaller 打包脚本待完善 | 中 |
| 国际化 | 当前仅支持中文，暂无英文计划 | 低 |
| 性能优化 | 表格虚拟滚动（>10000 条时）、AI 请求并发控制 | 低 |
| OFD 格式兼容性 | 不同厂商 OFD 差异大，需更多测试样本验证 | 中 |

## 8. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| AI API 不可用 | 无法使用 AI 学习功能 | 保留手动导入 + 规则配置作为降级方案 |
| OFD 格式不兼容 | 部分 OFD 解析失败 | 三层降级：XML 委托 → 正则匹配 → AI 学习 |
| PDF 扫描件无法提取 | PDF 导入失败 | 引导用户使用 AI 学习功能识别 |
| 凑票算法性能 | 大量发票计算超时 | 回溯 + 剪枝，限制最大搜索深度 |
| 数据库 Schema 变更 | 旧数据不兼容 | 迁移函数 `migrate()` + `ALTER TABLE` |
