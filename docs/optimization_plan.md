## 4. v2.0 — 专业版（规划中）

### 4.1 PyInstaller 打包完善（P0，预估 1 天）

| 项目 | 说明 |
|------|------|
| 目标 | `ai_fapiao.spec` 能正确生成可分发的单文件 EXE |
| 问题 | 当前 spec 文件中 `datas` 不完整，缺少 matplotlib 和 PyMuPDF 运行时依赖 |
| 方案 | 补充 `hiddenimports`（fitz, matplotlib.backends）+ 测试打包后运行 |
| 验收 | 全新 Windows 环境运行 EXE 无报错，所有功能可用 |

### 4.2 性能优化 — 虚拟滚动（P1，预估 1 天）

| 项目 | 说明 |
|------|------|
| 背景 | InvoiceTable 使用 QTableWidget 全量加载，>10000 行时明显卡顿 |
| 方案 | 分页加载（每页 200 行）+ 滚动到底部自动加载下一页 |
| 替代方案 | 改用 QTableView + QSqlTableModel 直连数据库 |
| 配合 | 搜索/筛选时使用 COUNT 总数 + LIMIT/OFFSET 分页查询 |

### 4.3 AI 能力增强 — 智能分类建议（P1，预估 2 天）

| 项目 | 说明 |
|------|------|
| 功能 | 导入发票后 AI 自动建议业务类型 + 检测异常（重复/金额异常） |
| 技术方案 | 基于发票号码+金额的去重检测 + 调用 AI 分析销售方推断业务类型 |
| 集成点 | ImportService 导入完成后调用 `ai_service.suggest_category()` |
| 展示 | 导入结果对话框新增"AI 建议"列 + 异常标记（⚠️） |

### 4.4 数据可视化增强 — 报销趋势看板（P2，预估 1.5 天）

| 项目 | 说明 |
|------|------|
| 功能 | 新增"报销趋势"看板：月度报销金额趋势 + 各业务占比变化 |
| 技术方案 | matplotlib 多子图布局 + 时间滑块筛选 + 数据下钻 |
| 数据源 | `SELECT strftime('%Y-%m', invoice_date), SUM(total_amount) GROUP BY ...` |
| 交互 | 点击图表元素 → 筛选对应发票列表 |

### 4.5 多端数据同步（P2，预估 3 天）

| 项目 | 说明 |
|------|------|
| 功能 | WebDAV / 坚果云同步数据库和规则文件 |
| 方案 | 增量同步（基于 import_time 时间戳）+ 冲突检测（last_write_wins）|
| 安全 | 传输前 Fernet 加密数据库 + 同步后自动解密 |
| UI | 设置页新增"云同步"开关 + 同步状态指示器 |

### 4.6 跨平台支持（P3，预估 2 天）

| 项目 | 说明 |
|------|------|
| 目标 | 支持 macOS / Linux 运行 |
| 方案 | PyQt5 本身跨平台 → 适配路径分隔符 + 打包 per-OS spec |
| 风险点 | Windows 特有的 `os.startfile()` 需替换为 `subprocess` + `xdg-open` / `open` |
| 测试 | CI 矩阵：Windows + macOS + Ubuntu |
