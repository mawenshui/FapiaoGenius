## 2. v1.3 — 完善版（预估 5 人天）

### 2.1 自动更新功能（1 天，P1）

| 项目 | 说明 |
|------|------|
| 功能 | 启动时检查版本 → 下载更新包 → 提示安装 |
| 技术方案 | urllib 请求 GitHub Release API → 对比版本号 → 下载 MSI/EXE → 调用安装程序 |
| 参考 | bianqian 项目 updater 实现 |

### 2.2 发票统计报表（1.5 天，P1）

| 项目 | 说明 |
|------|------|
| 功能 | 按业务类型/月份/金额区间统计 + 图表展示 |
| 技术方案 | matplotlib 或 pyecharts 生成图表 → 嵌入新页面或导出为图片 |
| 数据源 | InvoiceDAO 聚合查询（GROUP BY business_type / strftime） |

### 2.3 主题切换（1 天，P2）

| 项目 | 说明 |
|------|------|
| 功能 | 多套 QSS 主题文件 + 运行时切换 |
| 技术方案 | resources/styles/ 下放置多套 .qss → settings_page 选择 → 全局 reload |
| 参考 | bianqian 项目 theme_helper |

### 2.4 发票图片预览（1 天，P2）

| 项目 | 说明 |
|------|------|
| 功能 | PDF 首页渲染为图片 + 详情面板嵌入预览 |
| 技术方案 | PyMuPDF `fitz.open()` → `page.get_pixmap()` → QImage → QLabel |
| 位置 | DetailPanel 中新增预览区域 |

### 2.5 多用户配置支持（0.5 天，P3）

| 项目 | 说明 |
|------|------|
| 功能 | 配置按用户隔离或支持导入导出 |

## 3. v1.4 — 智能版（预估 5 人天）

### 3.1 OCR 扫描件识别（2 天，P0）

| 项目 | 说明 |
|------|------|
| 背景 | 当前 PDF 解析依赖 pdfplumber 文本提取，扫描件（图片PDF）无法识别 |
| 方案 | 集成 PaddleOCR / Tesseract → 图片预处理 → OCR → 正则提取 |
| 触发 | 当 pdfplumber 提取文本为空时自动降级到 OCR 通道 |

### 3.2 批量操作增强（1 天，P1）

| 项目 | 说明 |
|------|------|
| 功能 | 批量编辑字段、批量删除确认、批量导出选中项 |
| 方案 | InvoiceTable 多选模式 + Toolbar 批量操作按钮 + ConfirmDialog |

### 3.3 数据备份与恢复（1 天，P1）

| 项目 | 说明 |
|------|------|
| 功能 | 一键备份数据库 + 规则文件 → ZIP 包；支持从备份恢复 |
| 方案 | zipfile 模块打包 db + rules/ → 选择保存路径 → 恢复时验证完整性 |

### 3.4 高级搜索（0.5 天，P2）

| 项目 | 说明 |
|------|------|
| 功能 | 支持金额范围搜索、日期区间过滤、模糊匹配 |
| 方案 | SearchBar 增强 + InvoiceDAO 扩展 WHERE 条件 |

### 3.5 导出格式扩展（0.5 天，P2）

| 项目 | 说明 |
|------|------|
| 功能 | 除 Excel 外支持 CSV / PDF 报表导出 |
| 方案 | csv 模块 / reportlab 生成 PDF |
